# Vedant — AI Developer & Builder Portfolio

A premium, Gen Z-style personal portfolio built with plain **HTML, CSS and JavaScript** (no frameworks, no build step).

## Features
- Big hero with portrait, animated name and draggable stickers
- Skills marquee, bento-grid project cards with 3D tilt
- Google Summer of Code (GSoC) section
- Learning roadmap and achievements
- Light / dark mode toggle, scroll progress bar, scroll reveal animations
- Fully responsive

## Run locally
Just open `index.html` in your browser, or use VS Code's **Live Server** extension.

## Deploy with GitHub Pages
1. Push this folder to a GitHub repository.
2. Go to **Settings → Pages**.
3. Under **Source**, pick **Deploy from a branch**, choose `main` and `/ (root)`, then **Save**.
4. Your site goes live at `https://thevedantrajeshgawade8.github.io/<repo-name>/`.
